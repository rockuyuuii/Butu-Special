# Nanu loves Butu 🧿❤️‍🩹 v5

A pink, mobile-first RRB Nursing study and progress PWA designed around daily execution.

## v5 features
- Infinity love entrance gate
- Working Home, Daily, Goals, Progress, Rewards, Statistics, Planner, Habits, Focus, Insights and Settings sections
- Quick Study Tools that open real working features instead of blank pages
- Mobile bottom navigation bar + top navigation
- Working Back button with in-app previous-page history
- Daily target creation/edit/delete/check-off
- Study type selection: Video, MCQ, PYQ, Revision, Mock Test, Self Study, Non Nursing and Backlog Video
- Subject selection for nursing subjects and question-source tracking for MCQs/PYQs
- Topic, quantity, unit and priority controls
- Ultimate Goal Builder with separate targets for videos, MCQs, PYQs and study days
- Ultimate goal subject and deadline selection
- Automatic goal progress from completed daily targets
- 25/50-minute Focus Room with timer and Love Points
- Daily/monthly/yearly statistics
- 14-day progress history and progression charts
- 7-day planner
- Study habit checklist
- Growth Insights and 10-week activity heatmap
- Love Points, levels, badges, streaks and completion animations
- Backup/restore and local offline storage
- Custom subjects
- PWA install support

## Install
Open the GitHub Pages site in Chrome and choose **Install app** or **Add to Home screen**.
